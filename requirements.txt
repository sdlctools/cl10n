# A thin pointer at pyproject.toml — the dependencies themselves live there.
#
# This installs the package in editable mode with every provider SDK and the
# test dependencies: the contributor setup, and what CI installs.
#
#     python -m venv venv
#     venv/bin/pip install -r requirements.txt
#
# A *consumer* does not use this file. They install from PyPI and take only
# the provider they route to:
#
#     pip install markdown-localization[groq]
#
# WHERE THE PINS WENT, AND WHY THEY ARE PINS: the parsing stack
# (markdown-it-py, mdit-py-plugins, mdformat, mdformat-gfm,
# mdformat-frontmatter, linkify-it-py) is pinned EXACTLY in
# `pyproject.toml`'s `[project] dependencies`, with the full rationale in the
# comment directly above it. The short version: every unit hash in every
# translation memory is taken over that exact configuration, so a silent
# change in what the parser emits re-translates the whole corpus at full
# price. Read that comment before moving a pin, and run the drift detector:
#
#     venv/bin/python3 -m cl10n.compat_check
#
# The provider SDKs (groq, openai, mistralai) are NOT part of that contract —
# they never touch a hash — so they are unpinned extras and upgrade freely.

-e .[dev]
